Built a Postman-inspired API testing tool where users can send HTTP requests and inspect responses, with tabbed editors for Params, Auth, Headers and Body.
Implemented a server-side proxy route (/api/proxy) in Next.js to forward requests through the backend, which avoids browser CORS restrictions.
Managed dynamic key-value inputs (add/remove/toggle rows) with React state, in a fully typed TypeScript codebase.
Designed a beautiful UI with Tailwind CSS and deployed it on Vercel.
